\begin{frame}{}
\slidetitle{BACKUP}{Evaluation metrics}
\begin{columns}[T]
\column{0.5\textwidth}
\textbf{ROC-AUC}: chance a bad loan scores above a good loan\\[0.2cm]
\textbf{Gini} $=2\times$ AUC $-1$: standard score in credit risk\\[0.2cm]
\textbf{KS}: max gap between bad and good cumulative rates, $\max(\mathrm{TPR}-\mathrm{FPR})$\\[0.3cm]
No probability cut-off is needed: all three measure ranking quality. The same function is used for every model and data set.
\column{0.48\textwidth}
\footnotesize
\begin{block}{NB03 cell 5}
\texttt{def calculate\_metrics(y\_true, proba):}\\
\texttt{\ \ auc = roc\_auc\_score(y\_true, proba)}\\
\texttt{\ \ gini = 2 * auc - 1}\\
\texttt{\ \ fpr, tpr, \_ = roc\_curve(y\_true, proba)}\\
\texttt{\ \ ks = np.max(tpr - fpr)}\\
\texttt{\ \ return auc, gini, ks}
\end{block}
\end{columns}
\end{frame}

\begin{frame}{}
\slidetitle{BACKUP}{Known limits}
\begin{itemize}
\item Model covers 36-month loans only; test has only 3 months of late 2015
\item 32 columns are empty in train; 17 of them only start in val/test
\item ``Months since event'' columns were removed ($>30\%$ missing) though missing may mean ``never happened''
\item \code{issue\_d} is used in place of application date; only accepted loans exist in the data
\item RF and HistGB tuning grids hit the edge of the search space
\item One-hot gives 108 sparse dummies: fits Logistic well, harder for trees
\item Scorecard constants (600, PDO 20, odds 5:1) are conventions, not checked against an official standard
\end{itemize}
